Home Commands Rules

General Commands

  • /help — Show all commands
  • /ping — Check bot latency
  • /info — Get Frostz MC bot info

Messaging

  • /dmall [message] — Send a message to every server member 📬
  • /announce [channel] [message] — Post announcements 📢

Moderation

  • /kick @user — Kick a user
  • /ban @user — Ban a user
  • /mute @user — Temporarily mute a user
